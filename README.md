# QuoteBoard React Starter

QuoteBoard is a Vite React single-page application demonstrating client-side routing with `/` and `/quote/:id` routes.

## Available Routes
- `/`: QuoteBoard homepage showcasing curated quotes
- `/quote/:id`: Individual quote details page (e.g. `/quote/1`)

## Local Development
```bash
npm ci
npm run dev
```

## Production Build
```bash
npm run build
```
